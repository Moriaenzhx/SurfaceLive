## 两轮改动的影响

| 区域 | 从历史版到恢复前 | 此次恢复 |
| --- | --- | --- |
| 标题栏 | 居中的项目名移入左侧切换器，新建、版本和面板控制移到标题栏，第二轮去掉了品牌字标 | 恢复左侧原标记与字标、居中项目名、右侧专注与导出 |
| 项目对话 | 项目选择离开对话栏，真实缩略图与继续修改入口移除，输入区缩为单行并把工具移到加号内 | 恢复项目选择、示例缩略图、消息、修改入口、输入区和直接可见的加图、框选与引用按钮 |
| 工作区 | 点阵与居中画布改成顶部对齐的平面背景，视口标注移入工具栏，状态栏横跨窗口 | 恢复原画布位置、留白、设备控件、作品上方尺寸和画布底部状态 |
| 检查器 | 默认收起，标题与标签合并，版本移入标题栏菜单，页面设置减少 | 恢复原右栏、页面级属性、选取入口、版本列表与 Live Engine 页脚 |

| 品牌资源 | 变化发生在工作台 HTML 和 CSS 对品牌的展示；App 图标采用同一资源 | 原有界面标记随源码恢复，macOS 图标与原 icns 的 SHA-256 一致 |

## 恢复文件与业务边界

- `desktop/ui/index.html`、`studio.css`、`editor.css`、`studio.js`、`editor.js`。基础样式表 studio.css 与历史文件逐字节一致。其余四个文件保留了后装入的功能及必要的控件适配。
- 保留最近的自定义缩放、独立收起面板、预览加载及故障定位、元素路径、颜色、尺寸单位、交互属性、引用复用、草稿恢复，以及把未保存样式一起导出。缩放与面板折叠从原画布缩放入口调用。
- `desktop/tests/editor.mjs`、`smoke.mjs`、`workbench.mjs` 更新为恢复后的实际入口。项目 README 同步更新使用说明。恢复审计脚本位于 [states.mjs](../../runs/restore-two-back/states.mjs)。
- 后端、Live Engine、Agent 桥接、知识库、两份内置业务前端和导出实现均未编辑。恢复前后构建目录排除 UI 后逐文件比较一致。恢复过程没有执行 Git reset、重建项目或迁移用户资料。
