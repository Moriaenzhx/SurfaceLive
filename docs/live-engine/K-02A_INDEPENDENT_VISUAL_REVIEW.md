## 下一轮可以直接复用的两个任务

1. **知时，验证提交后的重心。** 固定同一套四柱、事项和日期范围。保留输入态与提交后的自然落点，让评阅者指出第一条候选、理由入口和编辑条件入口。品牌识别与寻找结果的难度分别记录。
2. **招聘，验证设备转换。** 使用同一岗位、同一候选人和同一处待补证事实。桌面看能否并行核对名单和原文。手机在搜索后先保留自然落点，再将两侧对齐到同一条已展开证据，分别检查身份、缺口、出处和复核动作的可见性。

如另行启动对照生成，需事先统一 Agent、模型、推理强度、时间上限和全流程 Token 预算，并记录实际消耗。真人评阅按当次匿名组号、样本号和理由回收，完成后再解盲。本轮交付到截图审查与待验证记录为止。
