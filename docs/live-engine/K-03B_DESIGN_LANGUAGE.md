# K-03B · 设计语言的来源、选择和使用

这五份 Seed 提供可以单独借用的设计原则。每份记录自己的适用业务、排除场景、品牌气质、构图、字阶、材料、组件行为、设备转换和有前提的反模式。未设定品牌色号、字体文件、固定圆角或页面结构模板。每份 Seed 的审核状态均为 `authored-unreviewed`。来源截图的既有检查记录与新归纳的设计方向分别保存。[完整 Seed 与来源数据](../../live-engine/design/language-seeds.json)

| Seed | 哪个业务判断需要它 | 如何把判断变成界面 | 迁移边界 |
|---|---|---|---|
| `daily-index` 日序读本 | 在一组候选时段中阅读并保存适合自己安排的选项 | 查询后收起条件，以日期为章、时段为条、理由为行内说明。汉字与数字分别承担叙事和比较。 | Nearby 截图支持同一条目中的名称与读数邻接。没有从该图推出文化语言、历法依据或推荐精度。 |
| `guided-sequence` 步骤手册 | 当前输入、补充证据或纠错完成后才可推进 | 每次突出一个问题，已确认内容变成可回看的摘要。输入、错误和下一步相邻，提交中保留值。 | 多人并行比较仍需要名单或总览。把整个复核工作台拆为向导会增加切换成本。 |
| `evidence-register` 证据对照册 | 在多位候选人、要求和缺口之间核对人工结论 | 稳定的对象行头与从属证据对齐。桌面留宽给原文，手机打开详情后保留人选、来源和返回路径。 | GnuCash 的主从行仅作为邻接机制的证据。业务结论来自当前复核对象及其证据。 |
| `signal-window` 时窗观察台 | 判断异常何时发生并与基准核对 | 多条趋势沿共享的时间轴比较，主变化之前交代时窗，读数旁保留口径。窄屏先选异常再展开趋势。 | 缺少时间或口径时，不具备画出连续监测曲线的依据。 |
| `media-stage` 素材校样台 | 剪辑者要保住当前帧、选区和时间坐标 | 预览保持稳定；时间码使用对齐的数字，参数和工具围绕当前选择展开。手机保留预览和当前轨道。 | 中性工作面服务素材判断，不应给作品本身叠品牌滤镜。 |

## 哪些证据支持这些原则

## 入选与拒绝

`matchDesignSeeds` 用用户原文与已有 Scene 维度进行词项匹配。业务任务命中是入选前提。结构、受众、文化品牌/视觉偏好和目标设备可在入选后调整顺序；单独说“高级”或选择手机不会触发任意领域的 Seed。每个匹配项返回命中的词项、评分维度、各维度得分和出处。最多送入两份，任务无命中时返回空。这个排序是可解释的词项基线，不能从词项重合推导专业审美偏好，也无法穷尽否定表达。[匹配、校验与注入代码](../../live-engine/design/design-language.mjs)

导演按候选逐项写出选择理由和使用边界。`original` 表示全部拒绝或没有入围 Seed，`adopt` 取用一份，`combine` 从两份各取至少一条原则。宿主校验候选 ID、原则 ID、重复和遗漏。各方向分别说明视觉差异、信息架构差异及 Token 选择依据。编码阶段只需该方向实际采用的原则、来源和业务化指导。相同知识 ID 可分别出现在 Seed 的参考谱系和导演直接引用的案例中，两种用途应分别查阅。

以 K-03A 冻结业务原文直接运行 B 层匹配，知时入围日序读本和步骤手册，招聘入围证据对照册和步骤手册。当次导演候选段落分别为 4,902 和 5,097 个 UTF-8 字节，数值不含原有知识检索或源码指令。真实 K-03B 导演如何取舍以其运行轨迹为准。可以用以下命令独立核对数据出处、未知场景、组合和拒绝行为。[覆盖用例](../../desktop/tests/design-language.test.mjs)

```sh
node --experimental-strip-types --test desktop/tests/design-language.test.mjs
```

## 两次实际导演决策

本机 Codex 为每个需求一次返回两个方向。以下比较来自四份通过校验的 1.1 契约，内容哈希已对回各自的 Trace。两份入选契约进入首稿编码；备选只保留决策记录。表中的尺寸与颜色均为编码前的约定，浏览器执行结果另见本批测试报告。

**知时。** 实际 Scene 与需求共同匹配到日序读本 **21 分**、步骤手册 **14 分**，导演输入的 Seed 段为 **4,902 字节**。步骤手册较上文仅凭原始需求匹配时多了场景维度输入。分数衡量词项与任务的相关程度，最后选择仍由导演给出。[导演回答](../../runs/K-03B/zhishi-56Umty/attempt/steps/art-direction/response.json) · [匹配依据及调用轨迹](../../runs/K-03B/zhishi-56Umty/attempt/design-trace.json)

| 方向 | 实际取舍 | 可核验的工程决定 |
|---|---|---|
| **入选 · 按日读时段** | 采用日序读本的构图、排版、交互与设备转换，拒用步骤手册。结果按日组织，点开理由后仍能扫读当天的相邻选项。宽屏把条件留在侧栏，手机把条件收为可编辑摘要。这个选择接受长日期范围需要更多滚动的代价。 | `type.size.body=16px`、`type.size.heading=26px`、`space.component.md=16px`。导演另用 8px 行内和 24px 组间留白表达同日与跨日的差别。品牌色 `#293F70` 由本方向提出，实际采用的四条 Seed 原则中没有颜色材料项。[入选契约](../../runs/K-03B/zhishi-56Umty/attempt/contracts/4c9bc501-9b19-47c1-a1ad-7c0c5e617fb2.json) |
